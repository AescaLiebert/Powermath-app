# Test Plans

Output directory for QA Agent test plans and regression checklists.

## Naming Convention

| Type | Pattern | Example |
| --- | --- | --- |
| Test Plan | `{feature-name}-test-plan.md` | `parry-timing-test-plan.md` |
| Regression | `{bug-name}-regression.md` | `input-buffer-regression.md` |

For lifecycle and contracts, see `Docs/2_System_Files/Handoff_Contracts/README.md`.
