# Math:World Icon-Driven UI Prompt Set — v15

## Status

This set applies `master-prompt-guide-art-direction-v14.md` to Leaderboard, private Profile Analytics, and Player Hub.

- `animo-gacha-banner-flat-v10.png` and `animo-gacha-result-flat-v10.png` are the sole visual authorities.
- `leaderboard-pet-gacha-v13.png` and `player-hub-pet-gacha-blend-v12.png` are information/content references only.
- Names, values, portraits, charts, and geometric Animo remain non-canon presentation placeholders.
- No Unity implementation or asset replacement is authorized by this concept set.

## Shared lock

- Icon first; repeated metrics use icon plus value.
- Warm-cream paper cards, one thin navy/cool-gray contour, shallow shadow, cyan/cobalt field, green selected state, restrained rank/coral accents, and subtle paper grain.
- Human portraits use simplified color masses, thin local-color contours, sparse interior lines, one hard shadow, one soft gradient, and selective eye detail.
- Animo and equipment use two or three color masses, firmer colored contours, one hard shadow, tiny AO, and one highlight.
- No paragraphs, repeated column labels, thick black lineart, glossy rendering, ornamental frames, glass panels, dark slabs, or decorative filler.

## Leaderboard prompt

Graphic UI. Build the same flat cyan/cobalt/cream pattern stage as the Pet Gacha result screen. Make the pinned green self row and its Best Stage icon/value the primary focal point. Use one title, one locked grade chip, info/refresh/close icons, a compact first-place avatar portrait card, and five ranked rows. Each row contains rank badge, simplified avatar and name, large Best Stage icon/value, smaller Current Stage icon/value, three Rank Currency icons/values, pet icon, weapon icon, and optional quiet damage icon/value. Top three use compact Diamond, Gold, and Silver badges with restrained edge accents. Use no full-body character, throne, formula subtitle, repeated metric labels, physical environment, or unique VIP frames.

Literal text: `LEADERBOARD`, `GRADE 4 · LEVEL 1`, `YOU`, and placeholder display names only.

## Profile Analytics prompt

Graphic UI popup. Center one large cream panel over the quiet Pet Gacha pattern stage. Make the identity strip and one Learning Trend chart dominant. Use a simplified avatar bust, display name, grade chip, rank/leaderboard/honor icon-values, edit icon, and close icon. Keep Adventure, wallet, and loadout in compact icon cards. Beneath the main trend, use smaller by-rank bars, one outcome donut, and one recent rank-history strip. Separate accuracy and response metrics visually. Never expose current audit score/count, audit thresholds, mean/median audit score, login username, peer data, or punitive language. Do not use the older parchment/gold analytical-dashboard direction.

Literal text: `MY PROFILE`, `NOVA`, `GRADE 4 · LEVEL 1`, `ADVENTURE`, `LEARNING TREND`, `BY RANK`, `RECENT`.

## Player Hub prompt

Scene UI with a deliberately simplified wardrobe. Keep the heroine and equipped aqua Animo standing on the floor outside every panel, but render them with broad masses, few interior lines, restrained gradients, and lower priority than the selected pet. Reduce the room to one arched window, mirror silhouette, garment rack, boot shelf, weapon stand, and broad floor shapes. Use one cream workspace with icon-only paw/sword tabs, a spacious 3×3 pet grid, green selected check state, large pet preview, rarity icons, and two ability icon rows without prose. Use icon-value chips for ATK/CR/CD, currencies, and equipped pet/weapon. No Player Summary panel, Equip button, nested frames, busy props, realistic wood texture, or text-heavy ability descriptions.

Literal text: `HUB`, `TEARAY`.

## Validation result

- Leaderboard removes the full-body hero, formula subtitle, and repeated row labels.
- Profile Analytics uses one dominant chart and compresses supporting information into icon groups.
- Player Hub reduces wardrobe, character, and panel detail while preserving grounded context and immediate equipped state.
